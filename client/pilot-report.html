LLM-LLM Phase 1 Pilot Report

One Claude Haiku 4.5 pair was tested in the two-player grid game. The baseline and signaling conditions each completed 10 Phase 1 rounds.

Design

Experimental Manipulation

The manipulation was whether the agents had access to a communication action.

  • Baseline: each player could choose only four movement actions: up, down, left, right.
  • Signaling: each player could also choose signal, meaning “I intend to capture the large moving target.” Signal costs -0.1 points and consumes the acting player’s turn.

Measures

  • Final score for each player and pair-total score.
  • Round outcome: large target capture, small target capture, or timeout.
  • Steps per round and player actions per round.
  • Signal use in the signaling condition.

Data-saving code now writes each experiment checkpoint to gameCode/data/experiments/, so interrupted runs keep the latest round data.

Interpretation

Baseline performance was already weak: 6 of 10 rounds reached the action limit, and the pair finished below zero despite two large-target captures. Signaling did not rescue coordination. The agents used signal four times, but the signaling run had fewer large-target captures, no small-target captures, more timeouts, and a lower final pair score.

The strongest conclusion is methodological: the current setup is good enough to run LLM-LLM pilots, but this prompt/policy combination produces poor spatial planning. A full experiment should use the new saved-data path and rerun matched baseline and signaling conditions across more seeds or pairs.
