Full Shared Agency Model Flow

A conceptual diagram for the shared-agency model family: infer a latent joint goal, combine it with an unshaped JointRL value model, then act through a goal-conditioned or signaling policy.

Core Pipeline

The full model can be understood as four linked computations. Existing model variants are ablations that turn some of these stages on/off or change when they start.

Stage 1

Flexible Joint-RL Policy

No explicit joint goal has been established yet, so action is generated by joint-RL over the current goal set.

\[\pi_{\mathrm{early}}(a)=\pi_{\mathrm{joint}}(a\mid s_t,\mathcal G_t)\]
No commitment parameter yet This is the flexible baseline used before the agent has enough evidence for a specific joint goal.
→
Stage 2

Infer Joint Goal

The agent maintains a posterior over candidate joint goals from observed actions under goal-conditioned joint policies.

\[P_t(g)\propto P_{t-1}(g)\prod_i\pi_{\mathrm{joint}}^i(a_{t-1}^i\mid s_{t-1}^i,s_{t-1}^{-i},g)\]
Confidence statistic \(C_t=\max_g P_t(g)\)
→
Stage 3

Gate Into Joint-Goal Sampling

Once inferred joint-goal confidence is high enough, the model shifts from flexible joint-RL toward sampling a specific joint goal.

When does sampling start? There are three useful modes:

  • After new-goal presentation: simplified assumption that the new-goal event is the moment a shared joint-goal decision becomes clear.
  • Sigmoid threshold: sampling gradually turns on as posterior confidence \(C_t\) crosses threshold \(\tau\).
  • From trial start: sample from \(W_\lambda(g)\) at every step with an initial uniform prior.
\[\rho_t=\sigma(k(C_t-\tau))\]
\[W_\lambda(g)\propto \exp(3\widetilde V_g(s_t))P_t(g)^\lambda\]
\[\widetilde V_g(s_t)=\frac{V_g(s_t)-\min_{g'}V_{g'}(s_t)}{\max_{g'}V_{g'}(s_t)-\min_{g'}V_{g'}(s_t)+\epsilon}\]
\[R_g(s,a,s')=30\,\mathbf 1[\mathrm{both\ reach\ }g]-1\,\mathbf 1[\mathrm{not\ done}],\quad \gamma=.9\]
\[g_t\sim \mathrm{Categorical}(W_\lambda(g))\]
If \(\lambda=0\): posterior belief no longer biases goal sampling, so \(W_\lambda(g)\propto \exp(3\widetilde V_g(s_t))\). The agent chooses among goals only by the unshaped JointRL value model.
Free parameters 1–2 \(\tau\): confidence threshold for starting joint-goal sampling. \(\lambda\): commitment/posterior strength in the sampled-goal distribution.
→
Stage 4

Act, With Optional Signaling

After selecting a joint goal, the agent can either follow the goal-conditioned joint policy or bias actions to make the goal more legible. There are two useful implementations.

\[P(g\mid a)\propto P(g)\pi_{\mathrm{base}}(a\mid s_t,g)\]

Approach A: RSA / log-posterior signaling. Theoretical soft bias toward actions that increase the listener posterior for the selected goal.

\[\pi_{\mathrm{signal}}(a\mid g^*)\propto \pi_{\mathrm{base}}(a\mid s_t,g^*)P_t(g^*\mid a)^\alpha\]
If \(\alpha=0\): the legibility term drops out, so \(\pi_{\mathrm{signal}}(a\mid g^*)=\pi_{\mathrm{base}}(a\mid s_t,g^*)\). In the current shared-agency model, \(\pi_{\mathrm{base}}\) is the unshaped JointRL marginal action policy.

Approach B: Bernoulli mixture signaling. Recommended fitted implementation: usually take the committed action, but sometimes replace it with the most legible progress action.

\[a_{\mathrm{leg}}(g^*)=\arg\max_{a\in\mathcal A^+(g^*)}P(g^*\mid a)\]
\[\pi_{\mathrm{signal}}(a\mid g^*)=(1-p)\pi_{\mathrm{committed}}(a\mid g^*)+p\,\delta_{a_{\mathrm{leg}}(g^*)}(a)\]
If \(p=0\): signaling reduces to the committed policy. If \(p=1\): the agent always takes the most legible progress action toward the sampled goal.
Free parameter 3 \(\alpha\) for RSA/log-posterior signaling, or \(p\) for mixture signaling. Higher values favor moves that better reveal the sampled goal.

One Full Model Equation

The most compact version is a soft mixture between flexible joint-RL and committed-signaling control.

\[ \pi(a) = (1-\rho_t)\pi_{\mathrm{joint}}(a\mid s_t,\mathcal G_t) + \rho_t\sum_g W_\lambda(g)\pi_{\mathrm{signal}}(a\mid g) \]

Intuition: before confidence is high, \(\rho_t\approx 0\), so behavior is mostly flexible joint-RL. After confidence crosses the threshold, \(\rho_t\approx 1\), so behavior becomes goal-conditioned and potentially signaling.

Free-Parameter Components

\(\tau\)

When to start committing

Controls the confidence midpoint for leaving flexible joint-RL.

\[\rho_t=\sigma(k(C_t-\tau))\]
\(\lambda\)

How strongly to commit

Controls how much posterior belief affects sampled joint-goal weights.

\[W_\lambda(g)\propto \exp(3\widetilde V_g(s_t))P_t(g)^\lambda\]
\(\alpha\) or \(p\)

How strongly to signal

Controls how much action choice favors listener inference of the selected goal. Use \(\alpha\) for the RSA/log-posterior form, or \(p\) for the fitted mixture form.

\[\pi_{\mathrm{RSA}}(a\mid g^*)\propto \pi_{\mathrm{base}}(a\mid s_t,g^*)P_t(g^*\mid a)^\alpha\]
\[\pi_{\mathrm{mix}}(a\mid g^*)=(1-p)\pi_{\mathrm{committed}}(a\mid g^*)+p\,\delta_{a_{\mathrm{leg}}(g^*)}(a)\]

Interpretation

This framing separates shared agency into three psychologically meaningful control knobs: when a shared intention is strong enough to matter, how strongly the agent follows that inferred joint goal, and how much it makes that goal legible to the partner.
