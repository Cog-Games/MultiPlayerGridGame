Model

The agent uses from-start joint-goal sampling from AlwaysSignalAgent, with goal values and RSA base-action likelihoods from the same unshaped JointRL reward model. The fit objective is trial/player-level commitment plus signaling binomial NLL by distance condition.

\[ W_\lambda(g) \propto \exp(3\widetilde V_g(s_t))P_t(g)^\lambda,\qquad \pi_{\mathrm{RSA}}(a\mid g)\propto \pi_{\mathrm{base}}(a\mid s_t,g)P_t(g\mid a)^\alpha \]
\[ R(s,a,s')=30\,\mathbf 1[\mathrm{both\ reach\ }g]-1\,\mathbf 1[\mathrm{not\ done}],\quad \gamma=.9,\quad \mathrm{softmax}\ \beta=3,\quad \mathrm{proximityRewardWeight}=0 \]
