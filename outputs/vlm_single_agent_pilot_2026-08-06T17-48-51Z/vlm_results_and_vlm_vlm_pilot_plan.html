2P2G block: coordination baseline

Eight trials for each pair; 40 total.

  • Use the human experiment’s first eight maps: keys 198–205.
  • Keep the current 2P2G game-rule text and sectioned prompt scaffold.
  • Both agents choose from the identical pre-move state; apply actions simultaneously.
  • Freeze an agent once it reaches a restaurant; let the partner finish.
  • Primary purpose: verify stable coordination and efficient joint navigation.

2P3G block: shared commitment

Twelve trials for each pair; 60 total.

  • Use the human experiment’s first twelve maps: keys 297–308.
  • Exactly three trials per condition within every pair.
  • Conditions: closer to traveler 1, closer to traveler 2, equal to both, and no new goal.
  • Randomize the balanced condition sequence with a saved pair-level seed.
  • Trigger the new goal only after both inferred trajectories indicate the same original goal.

Pre-specified analysis

What the pilot should answer

Pair is the independent unit; trial summaries are descriptive

2P2G: can two VLMs coordinate?

  1. Coordination success: both travelers finish at the same restaurant.
  2. Opportunity-adjusted makespan efficiency: shortest possible synchronized completion time divided by observed joint rounds; 100% is optimal.
  3. Total-path efficiency: optimal combined distance to a shared restaurant divided by the two observed path lengths.
  4. Coordination failures: split restaurants, timeout, loops, invalid actions, and transport failures reported separately.

2P3G: do two VLMs preserve a shared intention?

  1. Dyadic commitment: after a new goal appears, both finish at the originally inferred shared goal.
  2. Player-level commitment: each traveler’s final goal equals the original shared goal.
  3. Condition effects: report closer-to-P1, closer-to-P2, and equal-to-both separately; omit no-new-goal from commitment.
  4. Efficiency cost: compare opportunity efficiency and excess joint moves across all four conditions, including no-new-goal.

Recommended outputs

  • Pair-level table: success, efficiency, commitment, switching, and failures.
  • 2P2G bar plot: success and efficiency for each pair plus pooled descriptive mean.
  • 2P3G commitment plot: overall, closer-to-P1, closer-to-P2, and equal-to-both.
  • 2P3G efficiency plot: all four conditions, including no-new-goal.
  • Human comparison recomputed with the same formulas from full trajectories.
  • Cluster bootstrap by pair and Wilson intervals shown as descriptive uncertainty only.
Inference limit. Five pairs are suitable for debugging the paradigm and estimating effect direction and variance. They are not enough for a strong inferential human–VLM claim.

Reproducibility

Record the entire dyadic trajectory

One row per trial plus one nested record per synchronized step

At the trial level

  • Pair and agent IDs, model snapshot, temperature, map key, condition, and random seeds.
  • Start positions, initial goals, generated goal, trigger step, and realized distances.
  • Final goals, success/failure reason, rounds, moves, efficiency, and commitment outcomes.
  • Aggregate prompt/output/cached tokens, latency, cost, retries, and errors.

At every synchronized step

  • Shared pre-step state and grid image hash/path.
  • Exact prompt for each traveler, raw response, parsed action, usage, and latency.
  • Both inferred trajectory goals used by the game engine and the shared-goal trigger.
  • Both positions before/after applying the actions and the current restaurant set.

Operational sequence

  1. Run one excluded smoke pair for one 2P2G and one 2P3G trial; inspect prompts, simultaneous updates, and new-goal generation.
  2. Lock the exact model snapshot and save the generated condition schedules before any analyzed trial begins.
  3. Run five analyzed pairs with concurrency two; do not replace VLM actions with RL or committed-agent actions.
  4. Execute integrity checks before behavioral analysis: trial counts, balance, goal generation, missing data, retries, and fallback count.
  5. Generate pair-level tables and the pre-specified plots, then compare against human locked-action trajectories using identical measures.
